# project-map

A Claude Code skill for Angular repositories:

- **Structure map** Claude reads in every session (`docs/PROJECT_MAP.md`), regenerated by CI after each merge to main.
- **Branch report**: what the current branch changed compared with main, summarized for Claude at session start.
- **Rule check** for CI that fails only on structure issues a branch introduces.
- **Bubble graph** to explore the app and move files/folders by drag and drop (imports rewritten, `git mv`, undo).
- **Method-move preview**: select methods in a service, drop them on another service; the TypeScript compiler
  reports callers, helpers, shared state, circular dependencies, and a precise task for Claude.

## Use it

- As a plugin straight from this repository:
  ```
  /plugin marketplace add <owner>/<this-repo>
  /plugin install project-map@project-map-tools
  ```
- Or copy `skill/project-map` to `~/.claude/skills/`.
- Then in an Angular repo: `/project-map setup`.

Full documentation: [docs/1-SETUP.md](docs/1-SETUP.md), [docs/2-VALIDATION.md](docs/2-VALIDATION.md),
[docs/3-FEATURES.md](docs/3-FEATURES.md). Measured effect: [docs/experiments](docs/experiments/).

## Develop

```bash
./tests/run.sh                    # end-to-end tests on a temp copy of sample-app/
./scripts/sync-plugin.sh          # after editing skill/: refresh the plugin copy
./scripts/build-kit.sh            # dist/project-map-kit.zip for installing on another laptop
```

The source of truth is `skill/project-map/`. See [CLAUDE.md](CLAUDE.md) for the layout and working rules
(also what Claude Code reads when you develop this repo with it).
